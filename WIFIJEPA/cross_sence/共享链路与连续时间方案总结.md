# 共享链路与连续时间方案总结

本文总结 `WIFIJEPA/cross_sence` 中共享链路方案和连续时间方案的完整改进过程。所有结果均来自同一评测边界：

```text
protocol3 / strict / cross_scene_split / seed42 / 4shot
```

指标统一读取各实验的 `summary_absolute.json`，因此三项指标对应同一个按 Absolute MPJPE 选择的 checkpoint。JEPA-m2 的正确基线目录为：

```text
WIFIJEPA/result_metafi_ssl/wifi_jepa_amp/protocol3/cross_scene_split/seed42/4shot/ca2109a2d8-root0v1
```

## 一、共享链路方案

### 1. 研究目标

共享链路方案试图把三个 WiFi 链路中的共同人体信息与链路特有信息分开学习：

- shared 分支学习跨链路稳定信息；
- residual 分支保留链路差异；
- 下游姿态回归使用共享表示，同时尽量不丢失原始 CLS 中的绝对位置和姿态信息。

### 2. 改进历程

| 版本 | 核心改动 | Absolute | Pelvis | PA | 结论 |
|---|---|---:|---:|---:|---|
| 初始 v1 / CLS | shared predictor、residual predictor；shared mean 作为一种读出 | 382.910 | 124.784 | 104.655 | 共享表示可训练，但直接改变下游读出会损失信息 |
| 初始 v1 / shared mean | 对所有 token 做 shared mean | 393.324 | 133.277 | 109.747 | 平均操作进一步抹去链路和姿态差异 |
| v2 | 修复 residual 分支的梯度路径；统一 residual 的投影和归一化空间 | 404.684 | 125.430 | 105.618 | 实现修正必要，但强 consensus 目标仍然伤害表示 |
| v3 / shared CLS | link-specific target 重新作为主目标；shared consistency 降为辅助损失；下游使用 shared CLS | 357.607 | 121.784 | 102.995 | 首次超过 JEPA-m2，说明保留 link 信息是关键 |
| v3 / shared fusion | raw CLS 与 shared CLS 使用可学习门控融合 | **354.107** | 122.016 | 103.190 | 共享信息有效，但不应完全替换 raw CLS |
| v4 | 独立 residual projection 和 residual variance floor | 383.964 | 126.046 | 104.715 | residual 分解约束过强，破坏主姿态表示 |

相对于 JEPA-m2 基线 `359.718 / 123.464 / 103.967 mm`，最佳共享链路结果改善为：

```text
Absolute: -5.611 mm
Pelvis:   -1.448 mm
PA:       -0.777 mm
```

### 3. 最终采用版本

最终采用的是 **v3 预训练目标 + shared fusion 下游读出**。这里的“v3”指方法语义版本；当前 Python 类内部仍保留 `factorized_link_shared_v4` 的兼容标签，不能据此把最终方案误认为性能较差的 v4 独立 residual projection 实验。

预训练配置位于：

```text
WIFIJEPA/cross_sence/configs/factorized_link_shared.yaml
```

对应的最佳预训练目录为：

```text
WIFIJEPA/cross_sence/runs/pretrain_v3/protocol3/cross_scene_split/seed42/u20-e10-m2-dc0b6afd12
```

对应的最佳下游目录为：

```text
WIFIJEPA/result_metafi_ssl/wifi_jepa_amp/protocol3/cross_scene_split/seed42/4shot/7820fc0781-root0v1
```

### 4. 最终流程

```text
输入 CSI (B, 3, 114, 10)
        |
        v
StructuredTokenizer
  10 个时间位置 × 3 条链路 = 30 个 token
        |
        v
StructuredViT context encoder
  embed_dim=768, depth=6, heads=6, ffn_dim=3072
        |
        +------------------------------+
        |                              |
        v                              v
   shared projection             residual predictor
        |                              |
        v                              v
  link target prediction       link residual prediction
        |                              |
        +---------------+--------------+
                        v
                 EMA target encoder
```

预训练损失为：

```text
主损失：masked link target prediction
辅助损失：0.1 × shared consensus consistency
辅助损失：0.1 × residual prediction
```

关键原则是：每条 masked link 仍然预测自己的 target latent，shared consensus 只作为弱约束，不能替换原始 link target。

下游阶段使用：

```text
raw CLS -> shared projection + LayerNorm -> shared CLS
       \\                         /
        \---- learned gate --------/
                 |
                 v
fused = raw_cls + sigmoid(gate) × (shared_cls - raw_cls)
                 |
                 v
PoseHead: 768 -> 256 -> 128 -> 51 -> 17×3
```

训练得到的门控约为 `0.32`，表示模型保留大部分 raw CLS，同时吸收一部分共享链路信息。这解释了它比单独使用 shared CLS 更稳定。

## 二、连续时间方案

### 1. 研究目标

连续时间方案使用同一序列中的六帧 CSI，建模过去帧、anchor 帧和未来帧之间的关系，并让下游模型分别处理：

- anchor CLS：绝对位置和 root translation；
- temporal CLS：跨帧和相对姿态；
- temporal residual：相对于 anchor 的姿态变化。

时间窗口固定为：

```text
offsets = [-3, -2, -1, 0, +1, +2]
anchor frame = index 3
context frames = 4
future frames = 2
```

### 2. 改进历程

| 版本 | 核心改动 | Absolute | Pelvis | PA | 结论 |
|---|---|---:|---:|---:|---|
| v2 / 单帧下游 | 预训练含时间结构，但下游仍按单帧 CLS 使用 | 417.589 | 139.948 | 116.829 | 预训练时间信息没有被下游利用 |
| v2 / 真时序下游 | 六帧 temporal readout；anchor 与 temporal 分支联合回归 | **360.128** | **121.847** | **102.984** | 早期单次结果最好，证明时序下游结构有效 |
| v3 / full temporal | full temporal CLS 直接进入 masked prediction | 387.767 | 140.109 | 108.971 | 完整窗口信息泄漏，预训练目标与下游分布不一致 |
| v4 / masked consistency | 增加 full/masked temporal consistency | 377.099 | 138.302 | 106.133 | 一致性约束破坏运动和位置信息 |
| v5 / dual-view | masked temporal 为主，full temporal 为辅助 | 378.826 | 146.263 | 107.662 | full 分支仍干扰 masked 表示，pelvis 明显变差 |
| v6 / mask curriculum | joint mask 与 link-only mask 混合训练 | 431.872 | 152.675 | 113.255 | 两种输入分布冲突，预训练 loss 后期反弹 |
| v7 / stable v2 joint | 固定 joint mask；只保留 masked prediction；anchor + residual 下游 | 362.927 | 129.524 | 104.380 | 最稳定的最终版本，基本恢复 v2 能力 |

### 3. 最终采用版本

最终采用 **v7 stable v2 joint**，不是 v3/v4/v5/v6 的复杂化分支。它恢复了 v2 的有效核心，同时保留了后续修复：

- 固定 `joint` mask；
- `masked_links=1`；
- 只使用 masked prediction loss；
- 不使用 full/masked consistency；
- 不使用 link-only mask curriculum；
- temporal readout 只接收 masked temporal branch；
- 下游采用 anchor CLS + temporal residual。

配置位于：

```text
WIFIJEPA/cross_sence/configs/temporal_link_joint.yaml
```

最终预训练 checkpoint：

```text
WIFIJEPA/cross_sence/runs/pretrain/protocol3/cross_scene_split/seed42/u20-e10-m1-031b65b91f/encoder.pth
```

最终下游结果目录：

```text
WIFIJEPA/result_metafi_ssl/wifi_jepa_amp/protocol3/cross_scene_split/seed42/4shot/53b54b0a2c-root0v1
```

### 4. 最终流程

```text
六帧 CSI 窗口
[-3, -2, -1, 0, +1, +2]
        |
        v
每帧独立 StructuredViT encoder
  embed_dim=768, depth=6, heads=6, ffn_dim=3072
        |
        v
固定 joint mask
  link mask + future-frame mask
        |
        +-------------------------------+
        |                               |
        v                               v
masked frame CLS/token           EMA target encoder
        |                               |
        v                               v
temporal query + 6 frame CLS     target latent tokens
        |
        v
1-layer temporal Transformer
        |
        v
masked temporal CLS
        |
        v
Predictor 预测 masked target tokens
```

预训练只优化：

```text
masked prediction loss
```

未来帧被遮挡后，模型不能直接使用这些帧的真实 token；只能通过可见的历史/anchor 信息和 temporal query 预测目标 latent。EMA target encoder 只生成目标，不参与梯度更新。

下游流程为：

```text
六帧 CSI
   |
   v
六个 frame CLS
   |
   +--> anchor CLS (frame index 3) --> root head --> absolute root
   |
   +--> temporal Transformer --> temporal CLS
                                  |
                                  v
                         gated residual fusion
                                  |
                                  v
                         relative pose head
                                  |
                                  v
                       subtract joint-0 root
                                  |
                                  v
                 final pose = root + relative pose
```

绝对位置由 anchor 分支负责，temporal 分支只预测 root-relative 结构，从而避免对六帧做平均后丢失场景相关的全局位置。

## 三、两种方案的最终结果

| 方法 | 最终版本 | Absolute MPJPE | Pelvis MPJPE | PA-MPJPE |
|---|---|---:|---:|---:|
| JEPA-m2 基线 | ca2109a2d8-root0v1 | 359.718 | 123.464 | 103.967 |
| 共享链路 | v3 link-primary + shared fusion | **354.107** | 122.016 | 103.190 |
| 连续时间 | v7 stable v2 joint | 362.927 | 129.524 | 104.380 |

共享链路是本项目中最终指标最好的改进方案。连续时间方案在结构上证明了真实 temporal downstream 有效，但复杂化预训练目标均未超过稳定 v2 核心；因此最终保留 v7 作为可复现、稳定的时间连续版本。

需要区分“最终推荐版本”和“历史单次最低数值”：连续时间 v2 真时序下游曾得到 `360.128 / 121.847 / 102.984 mm`，数值略优于 v7，但 v7 是在修复 mask 分布、目标归一化和训练稳定性后的最终版本，预训练 loss 从第 1 轮的 `0.01389` 稳定下降到第 10 轮的 `0.000511`，因此作为最终方法版本保留。

## 四、最终结论

共享链路方案的有效部分是“保留 link-specific prediction，同时用弱 shared consistency 约束表示”，并在下游通过 raw/shared gate 融合，而不是强制所有链路收敛到同一个 consensus。

连续时间方案的有效部分是“真实六帧下游读取 + anchor 绝对位置 + temporal relative residual”。失败的部分主要来自预训练输入分布和目标设计：full temporal readout 会泄漏完整窗口信息，full/masked consistency 会抹平运动差异，joint/link mask curriculum 会制造冲突分布。

因此，研究到此结束时建议保留两条最终基线：

```text
共享链路：v3 link-primary + shared fusion
连续时间：v7 stable v2 joint
```

两者均使用严格的 cross-scene、4-shot、seed42 评测边界，后续不再继续增加新的预训练分支或 mask 复杂度。
